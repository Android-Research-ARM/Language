# Cómo contribuir

Gracias por ayudar a traducir ARAS. Puedes colaborar completamente desde GitHub sin necesidad de herramientas de programación.

## Antes de editar

- Verifica que has abierto el archivo de idioma correcto.
- Lee los [consejos de traducción](README.md#consejos-importantes-de-traducción).
- Busca en las pull requests abiertas para comprobar si alguien ya está trabajando en el mismo idioma.
- Traduce idiomas que domines con fluidez o solicita a un hablante nativo que revise tu trabajo.

## Enviar un cambio

1. Abre el archivo de idioma en GitHub.
2. Haz clic en el botón con forma de lápiz (**Edit this file**).
3. Modifica únicamente el texto traducido del lado derecho.
4. Usa **Preview changes** para comprobar tus modificaciones.
5. Selecciona **Propose changes**.
6. Asigna un título breve a tu propuesta, por ejemplo: `Mejorar traducción de ajustes en español`.
7. Abre la pull request.

En tu pull request, indícanos:

- Qué idioma has modificado
- Qué mejoras has realizado
- Si eres hablante nativo o fluido
- Si utilizaste traducción automática
- Qué frases, si las hay, necesitan revisión adicional

## Qué no modificar

- El texto en inglés del lado izquierdo
- Texto que empiece con `%`, como `%@`, `%ld`, `%s` o `%.1f`
- Marcadores de salto de línea `\n`
- Nombres de archivo o metadatos al inicio del archivo
- Más de un idioma en la misma pull request

## Nuevos idiomas

Por favor, abre una issue antes de crear un archivo nuevo. Indícanos el idioma, la región si corresponde, su nombre nativo y si puedes traducirlo o revisarlo. Un mantenedor creará el archivo correspondiente.

## Proceso de revisión

Los mantenedores comprueban la validez técnica del archivo. Hablantes fluidos revisan el significado, la gramática y el tono. Se trata de un proceso colaborativo y constructivo.

No incluyas mensajes ocultos, acoso, publicidad, enlaces, rastreadores ni datos personales.

## Permiso para compartir

Envía solo traducciones que tengas derecho a compartir. Al abrir una pull request, aceptas que tu aportación se publique bajo la [Licencia MIT](../../LICENSE) del repositorio.
