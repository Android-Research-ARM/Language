# Panduan Berkontribusi

Terima kasih telah membantu menerjemahkan ARAS! Semua proses dapat dilakukan melalui GitHub.

## Sebelum mengedit

- Pastikan berkas benar
- Pahami tips penerjemahan
- Periksa PR terbuka

## Mengirimkan perubahan

1. Buka berkas
2. Edit sisi kanan
3. Pratinjau perubahan
4. Buat pull request

Jelaskan bahasa, peningkatan yang dilakukan, dan kemampuan bahasa Anda pada deskripsi PR.

## Hal yang tidak boleh diubah

- Kunci bahasa Inggris di sisi kiri
- Penanda format `%@`, `%s`, `%ld`, `%.1f`
- Pemisah baris `\n`
- Metadata

## Bahasa baru

Silakan buka issue untuk permintaan penambahan bahasa baru.

## Proses peninjauan

Kolaborasi yang ramah dan mengutamakan mutu. Dilarang memasukkan spam.
