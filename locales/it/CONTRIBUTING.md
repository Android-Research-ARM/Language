# Come contribuire

Grazie per l'aiuto nel tradurre ARAS. Puoi contribuire direttamente via GitHub senza strumenti di sviluppo.

## Prima di modificare

- Verifica di aver aperto il file corretto.
- Leggi i [consigli per la traduzione](README.md#consigli-importanti-per-la-traduzione).
- Controlla le pull request aperte per evitare sovrapposizioni.
- Traduci solo nelle lingue che parli fluentemente.

## Inviare una modifica

1. Apri il file su GitHub.
2. Fai clic sull'icona a matita (**Edit this file**).
3. Modifica solo il testo sul lato destro.
4. Controlla con **Preview changes**.
5. Seleziona **Propose changes**.
6. Scrivi un titolo chiaro per la proposta.
7. Apri la pull request.

Nella descrizione della pull request indica:

- Quale lingua hai modificato
- Cosa hai migliorato
- Se sei madrelingua o parli la lingua fluentemente
- Se hai usato strumenti di traduzione automatica
- Eventuali frasi che necessitano di ulteriore revisione

## Cosa non modificare

- Il testo in inglese sul lato sinistro
- Segnaposto come `%@`, `%ld`, `%s`, `%.1f`
- Interruzioni di riga `\n`
- Metadati o nomi di file
- Più lingue nella stessa pull request

## Nuove lingue

Apri una issue prima di creare file. Un maintainer imposterà il catalogo corretto.

## Processo di revisione

I maintainer convalidano i file dal punto di vista tecnico e linguistico in un'ottica collaborativa.
