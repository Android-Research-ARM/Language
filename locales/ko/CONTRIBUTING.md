# 기여 가이드

ARAS 번역에 참여해 주셔서 감사합니다! 모든 작업은 GitHub에서 쉽게 완료할 수 있습니다.

## 편집 전 확인

- 올바른 파일 확인
- 번역 팁 숙지
- 진행 중인 PR 확인

## 변경 사항 제출

1. 파일 열기
2. 오른쪽 텍스트 편집
3. 변경 사항 미리보기
4. PR 생성

PR 설명란에 변경 사항, 개선점, 원어민 여부를 기재해 주세요.

## 수정하면 안 되는 항목

- 왼쪽 영문 키
- `%@`, `%s`, `%ld`, `%.1f` 지정자
- `\n` 줄바꿈
- 메타데이터

## 새 언어 추가

새 언어는 Issue를 통해 먼저 요청해 주세요.

## 검토 절차

상호 존중과 협력을 바탕으로 진행됩니다. 스팸 및 악성 내용은 엄격히 금지됩니다.

## 공유 권한

모든 기여물은 [MIT 라이선스](../../LICENSE)로 배포됩니다.
