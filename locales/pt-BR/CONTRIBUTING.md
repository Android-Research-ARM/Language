# Como contribuir

Obrigado por ajudar a traduzir o ARAS! Você pode colaborar totalmente pelo navegador através do GitHub.

## Antes de editar

- Verifique se abriu o arquivo de idioma correto.
- Leia as [dicas de tradução](README.md#dicas-importantes-de-tradução).
- Pesquise pull requests abertas para não duplicar tarefas.
- Traduza idiomas que você domina com fluência.

## Enviar uma alteração

1. Abra o arquivo no GitHub.
2. Clique no ícone de lápis (**Edit this file**).
3. Altere apenas o lado direito da linha.
4. Verifique com **Preview changes**.
5. Selecione **Propose changes**.
6. Dê um título objetivo à pull request.
7. Envie a proposta.

Descreva o idioma modificado, as melhorias feitas e eventuais dúvidas.

## O que não alterar

- O texto em inglês do lado esquerdo
- Marcadores como `%@`, `%ld`, `%s`, `%.1f`
- Quebras de linha `\n`
- Nomes de arquivos e metadados
- Mais de um idioma por pull request

## Novos idiomas

Abra uma issue informando o idioma para que um mantenedor configure o arquivo.

## Processo de revisão

Foco em qualidade colaborativa e precisão técnica. Conteúdos abusivos ou spam são proibidos.
