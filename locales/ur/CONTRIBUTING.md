# حصہ لینے کا طریقہ

ARAS کے ترجمے میں مدد کرنے پر آپ کا شکریہ! تمام ترامیم GitHub کے ذریعے کی جا سکتی ہیں۔

## ترمیم سے پہلے

- صحیح فائل کی تصدیق کریں
- رہنما اصول پڑھیں
- کھلی ہوئی Pull Requests چیک کریں

## تبدیلیاں جمع کروانا

1. فائل کھولیں
2. دائیں جانب ترجمہ کریں
3. تبدیلیاں چیک کریں
4. Pull Request بھیجیں

Pull Request میں کی گئی تبدیلیوں اور اپنی زبان کی مہارت کی تفصیل فراہم کریں۔

## کن چیزوں کو تبدیل نہیں کرنا

- بائیں جانب کے انگریزی الفاظ
- فارمیٹنگ علامات `%@`، `%s`، `%ld`، `%.1f`
- نئی لائن `\n`
- فائل کے میٹا ڈیٹا

## نئی زبانیں

نئی زبان کے لیے پہلے ایک Issue کھولیں۔

## جائزے کا طریقہ کار

معیار اور باہمی تعاون پر مبنی عمل۔ سپیم یا نامناسب مواد سختی سے منع ہے۔
