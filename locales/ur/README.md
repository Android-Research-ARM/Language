ARAS ہماری کمیونٹی کے ارکان کے ذریعے ترجمہ کیا جاتا ہے۔ اگر آپ اردو بولتے ہیں تو آپ اس کے مینیوز، بٹنز اور پیغامات کو مزید صارفین کے لیے قدرتی اور آسان بنانے میں مدد کر سکتے ہیں۔

آپ کو کسی پروگرامنگ کے تجربے، خاص سافٹ ویئر یا کوڈ تک رسائی کی ضرورت نہیں۔ تمام کام آپ کے ویب براؤزر میں براہ راست GitHub پر کیا جا سکتا ہے۔

## مدد کرنے کے طریقے

- نئی زبان شامل کرنا جو ابھی درج نہیں ہے
- ان جملوں کو مکمل کرنا جو ابھی انگریزی میں ہیں
- املا یا گرامر کی غلطیاں درست کرنا
- جملوں کی ساخت کو فطری اور عام فہم بنانا
- اصطلاحات کی یکسانیت کو بہتر بنانا
- دوسرے ساتھیوں کے ترجمے کا جائزہ لینا

ہر چھوٹی بڑی بہتری خوش آئند ہے۔ آپ کو ایک ساتھ پوری فائل کا ترجمہ کرنے کی ضرورت نہیں۔

## موجودہ زبان میں ترمیم کرنا

1. فائلوں کی فہرست میں اپنی زبان کا `.json` فائل تلاش کریں۔ مثلاً اردو کے لیے `ur.json` ہے۔
2. فائل کھولیں اور پینسل والے آئیکن (**Edit this file**) پر کلک کریں۔
3. ہر جوڑے میں صرف دائیں جانب والے ترجمہ شدہ متن کو تبدیل کریں۔
4. تبدیلیوں کی تصدیق کے لیے **Preview changes** پر کلک کریں۔
5. تبدیلی تجویز کرنے کے لیے **Propose changes** پر کلک کریں اور Pull Request بنائیں۔

```json
"Cancel": "منسوخ کریں"
```

بائیں جانب `Cancel` اصل انگریزی متن ہے۔ دائیں جانب `منسوخ کریں` اردو ترجمہ ہے۔ صرف دائیں جانب تبدیلی کریں۔

## نئی زبان کی درخواست

ایک نئی Issue کھولیں اور زبان کا نام، علاقہ اور ترجمہ یا جائزہ لینے کی دستیابی بتائیں۔

## ترجمے کے اہم رہنما اصول

- پروڈکٹ کا نام `ARAS` بغیر تبدیلی کے رکھیں۔
- Android، macOS، Mac، ProMotion اور Adreno جیسے نام بغیر ترجمہ کے رکھیں۔
- تکنیکی مخففات مثلاً ADB، QEMU، QCOW2، DPI، FPS اور GiB کو نہ بدلیں۔
- سلیس اور عام فہم اردو لکھیں، لفظ بہ لفظ سخت ترجمے سے گریز کریں۔
- مینیوز اور بٹنز کے نام مختصر اور واضح رکھیں۔
- اہم اصطلاحات جیسے ڈیوائس، ترتیبات، اسٹوریج، اپ ڈیٹ کے لیے یکساں الفاظ استعمال کریں۔
- ڈیٹا ڈیلیٹ کرنے یا ری سیٹ کرنے کی وارننگز واضح اور دوٹوک ہونی چاہئیں۔
- خاص علامات جیسے `%@`، `%ld`، `%s`، `%.1f` یا `\n` کو بالکل تبدیل نہ کریں۔
- مشینی ترجمے کا انسان کے ذریعے جائزہ لینا لازمی ہے۔
- کبھی بھی اشتہارات یا ذاتی معلومات شامل نہ کریں۔

`%@`، `%ld`، `%s`، `%.1f` اور `\n` جیسے متغیرات کو پروگرام خودکار طریقے سے تبدیل کرتا ہے۔

مزید رہنمائی کے لیے [ترجمہ اسٹائل گائیڈ](STYLE_GUIDE.md) ملاحظہ کریں۔
