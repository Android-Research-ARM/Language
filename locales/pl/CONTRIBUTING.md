# Współtworzenie

Dziękujemy za pomoc w tłumaczeniu ARAS! Wszystko można zrobić bezpośrednio przez stronę GitHub.

## Przed rozpoczęciem edycji

- Sprawdź poprawność pliku
- Przeczytaj wskazówki
- Sprawdź otwarte pull requesty

## Zgłaszanie zmian

1. Otwórz plik
2. Edytuj prawą stronę
3. Przejrzyj zmiany
4. Zaproponuj zmiany
5. Utwórz pull request

Opisz język, zakres wprowadzonych ulepszeń i znajomość języka w opisie pull requesta.

## Czego nie należy modyfikować

- Angielskich kluczy po lewej
- Znaczników `%@`, `%s`, `%ld`, `%.1f`
- Znaków nowej linii `\n`
- Metadanych pliku

## Nowe języki

Otwórz issue przed utworzeniem nowego pliku językowego.

## Proces weryfikacji

Współpraca ukierunkowana na jakość i wzajemny szacunek.
