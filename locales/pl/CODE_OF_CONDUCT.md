# Kodeks Postępowania Społeczności

Społeczność tłumaczy ARAS jest otwarta dla każdego.

## Oczekiwane zachowania

- Szacunek, cierpliwość i konstruktywne podejście
- Kulturalna dyskusja o niuansach językowych
- Ochrona prywatności

## Niedopuszczalne zachowania

- Nękanie, dyskryminacja, ataki osobiste
- Spam i celowo błędne tłumaczenia

## Egzekwowanie zasad

Opiekunowie dbają o przyjazną i bezpieczną atmosferę.
