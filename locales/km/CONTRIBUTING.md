# ការចូលរួមចំណែក

សូមអរគុណសម្រាប់ការជួយបកប្រែ ARAS!

## មុនពេលកែសម្រួល

- ពិនិត្យឯកសារឱ្យបានត្រឹមត្រូវ
- អានការណែនាំ
- ពិនិត្យមើល PR ដែលកំពុងបើក

## ការដាក់ស្នើការកែប្រែ

1. បើកឯកសារ
2. កែប្រែខាងស្តាំ
3. មើលការផ្លាស់ប្តូរជាមុន
4. បង្កើត Pull Request

រៀបរាប់ពីការកែលម្អរបស់អ្នកនៅក្នុងការពិពណ៌នា PR។

## អ្វីដែលមិនត្រូវកែប្រែ

- កូនសោអង់គ្លេសខាងឆ្វេង
- និមិត្តសញ្ញា `%@`, `%s`, `%ld`, `%.1f`
- ចុះបន្ទាត់ `\n`
- ទិន្នន័យមេតា

## ភាសាថ្មី

សូមបើក Issue មុនពេលស្នើសុំភាសាថ្មី។

## ដំណើរការពិនិត្យ

សហការដើម្បីគុណភាព និងការគោរពគ្នាទៅវិញទៅមក។

## ការអនុញ្ញាតចែករំលែក

ការចូលរួមទាំងអស់ត្រូវបានផ្សព្វផ្សាយក្រោម [អាជ្ញាបណ្ណ MIT](../../LICENSE)។
