# ជួយបកប្រែ ARAS

ARAS ត្រូវបានបកប្រែដោយសមាជិកនៃសហគមន៍របស់យើង។ ប្រសិនបើអ្នកចេះភាសាផ្សេងទៀត អ្នកអាចជួយធ្វើឱ្យ ម៉ឺនុយ ប៊ូតុង និងសារផ្សេងៗមានលក្ខណៈធម្មជាតិ និងងាយយល់សម្រាប់អ្នកប្រើប្រាស់កាន់តែច្រើន។

អ្នកមិនត្រូវការបទពិសោធន៍សរសេរកូដ ឬកម្មវិធីពិសេសនោះទេ។ អ្វីៗទាំងអស់អាចធ្វើឡើងនៅលើ GitHub តាមរយៈកម្មវិធីរុករកតាមអ៊ីនធឺណិតរបស់អ្នក។

## វិធីដែលអ្នកអាចជួយបាន

- បន្ថែមភាសាថ្មីដែលមិនទាន់មានក្នុងបញ្ជី
- បំពេញអត្ថបទដែលនៅតែជាភាសាអង់គ្លេស
- កែតម្រូវអក្ខរាវិរុទ្ធ ឬវេយ្យាករណ៍
- កែលម្អឃ្លាឱ្យកាន់តែរលូន និងធម្មជាតិ
- បង្កើនភាពស៊ីសង្វាក់គ្នានៃពាក្យបច្ចេកទេស
- ពិនិត្យមើលការបកប្រែពីអ្នករួមចំណែកដទៃទៀត

រាល់ការចូលរួមចំណែកតិចតួចសុទ្ធតែត្រូវបានស្វាគមន៍ជានិច្ច។

## កែសម្រួលភាសាដែលមានស្រាប់

1. ស្វែងរកភាសារបស់អ្នកក្នុងបញ្ជីឯកសារ `.json`។ ឧទាហរណ៍ ភាសាខ្មែរគឺ `km.json`។
2. បើកឯកសារ ហើយចុចលើរូបខ្មៅដៃ (**Edit this file**)។
3. កែសម្រួលតែអត្ថបទដែលបានបកប្រែនៅខាងស្តាំប៉ុណ្ណោះ។
4. ចុច **Preview changes** ដើម្បីពិនិត្យមើលការកែប្រែរបស់អ្នក។
5. ចុច **Propose changes** ហើយបង្កើត Pull Request។

```json
"Cancel": "បោះបង់"
```

ខាងឆ្វេង `Cancel` គឺជាអត្ថបទភាសាអង់គ្លេសដើម។ ខាងស្តាំ `បោះបង់` គឺជាការបកប្រែជាភាសាខ្មែរ។

## ស្នើសុំភាសាថ្មី

បើក Issue ហើយប្រាប់យើងពីឈ្មោះភាសា តំបន់ និងការត្រៀមខ្លួនរបស់អ្នកក្នុងការបកប្រែ។

## គន្លឹះសំខាន់ៗក្នុងការបកប្រែ

- រក្សាទុកពាក្យ `ARAS` ដោយមិនផ្លាស់ប្តូរ។
- រក្សាទុកឈ្មោះដូចជា Android, macOS, Mac, ProMotion និង Adreno។
- រក្សាទុកពាក្យកាត់បច្ចេកទេស៖ ADB, QEMU, QCOW2, DPI, FPS, GiB។
- សរសេរជាភាសាខ្មែរឱ្យមានលក្ខណៈធម្មជាតិ និងងាយយល់។
- រក្សាអត្ថបទម៉ឺនុយ និងប៊ូតុងឱ្យខ្លីល្មម។
- ប្រើប្រាស់ពាក្យដូចគ្នាសម្រាប់ ឧបករណ៍, ការកំណត់, ទំហំផ្ទុក, ការអាប់ដេត។
- ការព្រមានអំពីការលុបទិន្នន័យត្រូវតែច្បាស់លាស់ និងម៉ឺងម៉ាត់។
- កុំផ្លាស់ប្តូរនិមិត្តសញ្ញាដូចជា `%@`, `%ld`, `%s`, `%.1f` ឬ `\n` ឡើយ។
- ការបកប្រែដោយម៉ាស៊ីនត្រូវតែមានការផ្ទៀងផ្ទាត់ដោយមនុស្សផ្ទាល់។
- កុំបន្ថែមការផ្សាយពាណិជ្ជកម្ម ឬព័ត៌មានផ្ទាល់ខ្លួនឡើយ។

និមិត្តសញ្ញាដូចជា `%@`, `%ld`, `%s`, `%.1f`, `\n` នឹងត្រូវបានបំពេញដោយស្វ័យប្រវត្តិ។
