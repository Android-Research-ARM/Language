# දායක වීම

ARAS පරිවර්තනය කිරීමට සහාය වීම ගැන ස්තූතියි!

## සංස්කරණයට පෙර

- නිවැරදි ගොනුව තහවුරු කරගන්න
- උපදෙස් කියවන්න
- විවෘත PR පරීක්ෂා කරන්න

## වෙනස්කම් ඉදිරිපත් කිරීම

1. ගොනුව විවෘත කරන්න
2. දකුණු පස සංස්කරණය කරන්න
3. වෙනස්කම් පෙරදසුන් කරන්න
4. Pull Request එකක් යොමු කරන්න

සිදු කරන ලද වැඩිදියුණු කිරීම් PR විස්තරයේ දක්වන්න.

## වෙනස් නොකළ යුතු දෑ

- වම් පස ඉංග්‍රීසි යතුරු
- `%@`, `%s`, `%ld`, `%.1f` සංකේත
- `\n` පේළි කඩන
- පාරදත්ත

## නව භාෂා

නව භාෂාවක් සඳහා කරුණාකර Issue එකක් විවෘත කරන්න.

## සමාලෝචනය

ගුණාත්මකභාවය සහ සුහදත්වය පෙරදැරිව කටයුතු කෙරේ.

## බෙදා හැරීමේ අවසරය

සියලු දායකත්වයන් [MIT බලපත්‍රය](../../LICENSE) යටතේ නිකුත් කෙරේ.
