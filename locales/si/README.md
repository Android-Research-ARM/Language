ARAS අපගේ ප්‍රජාව විසින් පරිවර්තනය කරනු ලැබේ. ඔබට වෙනත් භාෂාවක් හැසිරවිය හැකි නම්, මෙනු, බොත්තම් සහ පණිවිඩ වඩාත් ස්වාභාවික හා පැහැදිලි කිරීමට ඔබට දායක විය හැක.

ක්‍රමලේඛන පළපුරුද්දක් හෝ විශේෂ මෘදුකාංග අවශ්‍ය නොවේ. සියල්ල GitHub හරහා වෙබ් බ්‍රවුසරයෙන් කළ හැක.

## සහාය විය හැකි ක්‍රම

- තවමත් ලැයිස්තුගත කර නොමැති නව භාෂාවක් එක් කිරීම
- තවමත් ඉංග්‍රීසි භාෂාවෙන් ඇති පෙළ සම්පූර්ණ කිරීම
- අක්ෂර වින්‍යාස හෝ ව්‍යාකරණ දෝෂ නිවැරදි කිරීම
- වචන භාවිතය වඩාත් ස්වාභාවික කිරීම
- පාරිභාෂිතයේ අනුකූලතාව වැඩිදියුණු කිරීම
- අනෙකුත් පරිශීලකයින්ගේ පරිවර්තන සමාලෝචනය කිරීම

කුඩා දායකත්වයන් පවා ඉතා අගය කරනු ලැබේ.

## පවතින භාෂාවක් සංස්කරණය කිරීම

1. `.json` ගොනු ලැයිස්තුවෙන් ඔබේ භාෂාව සොයා ගන්න. සිංහල භාෂාව `si.json` වේ.
2. ගොනුව විවෘත කර පැන්සල් නිරූපකය (**Edit this file**) මත ක්ලික් කරන්න.
3. දකුණු පස ඇති පරිවර්තන පෙළ පමණක් සංස්කරණය කරන්න.
4. **Preview changes** ක්ලික් කර වෙනස්කම් පරීක්ෂා කරන්න.
5. **Propose changes** ක්ලික් කර Pull Request එකක් සාදන්න.

```json
"Cancel": "අවලංගු කරන්න"
```

වම් පස `Cancel` යනු මුල් ඉංග්‍රීසි පෙළයි. දකුණු පස `අවලංගු කරන්න` යනු සිංහල පරිවර්තනයයි.

## නව භාෂාවක් ඉල්ලීම

Issue එකක් විවෘත කර භාෂාවේ නම සහ සහාය විය හැකි ආකාරය සඳහන් කරන්න.

## වැදගත් පරිවර්තන උපදෙස්

- `ARAS` නම වෙනස් නොකර තබන්න.
- Android, macOS, Mac, ProMotion, Adreno නම් එලෙසම තබන්න.
- තාක්ෂණික කෙටි යෙදුම් වෙනස් නොකරන්න: ADB, QEMU, QCOW2, DPI, FPS, GiB.
- ස්වාභාවික සිංහල භාෂාවෙන් ලියන්න.
- මෙනු සහ බොත්තම් පෙළ කෙටියෙන් තබන්න.
- උපාංගය, සැකසීම්, ආචයනය, යාවත්කාලීන වැනි වචන සඳහා ස්ථාවර යෙදුම් භාවිතා කරන්න.
- දත්ත මැකීමේ අනතුරු ඇඟවීම් පැහැදිලි විය යුතුය.
- `%@`, `%ld`, `%s`, `%.1f` හෝ `\n` කිසිවිටෙකත් වෙනස් නොකරන්න.
- ස්වයංක්‍රීය පරිවර්තන මිනිස් ඇසකින් පරීක්ෂා කළ යුතුය.
- වෙළඳ දැන්වීම් හෝ පෞද්ගලික තොරතුරු කිසිවිටෙකත් එක් නොකරන්න.

`%@`, `%ld`, `%s`, `%.1f`, `\n` වැනි සංකේත ස්වයංක්‍රීයව පිරවෙනු ඇත.
