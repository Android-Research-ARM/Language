# Чек-лист для проверки

Памятка для мейнтейнеров и рецензентов.

## Языковая проверка

- [ ] Смысл полностью соответствует оригиналу.
- [ ] Текст звучит грамотно и естественно по-русски.
- [ ] Терминология соблюдена во всех строках.
- [ ] Предупреждения об удалении сформулированы четко.
- [ ] Все оставленные на английском фразы согласованы.

## Техническая проверка

- [ ] Ключи слева не затронуты.
- [ ] Плейсхолдеры `%@`, `%s`, `%ld`, `%.1f` и `\n` на месте.
- [ ] Отсутствуют посторонние ссылки и спам.
