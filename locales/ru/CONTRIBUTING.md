# Руководство для участников

Благодарим за помощь в переводе ARAS! Все правки можно делать через веб-интерфейс GitHub.

## Перед началом работы

- Убедитесь, что открыли правильный языковой файл.
- Ознакомьтесь с [советами по переводу](README.md#важные-советы-по-переводу).
- Проверьте открытые Pull Request'ы, чтобы избежать дублирования работы.
- Переводите на языки, которыми владеете свободно.

## Отправка изменений

1. Откройте файл на GitHub.
2. Нажмите иконку карандаша (**Edit this file**).
3. Отредактируйте правую часть строк.
4. Используйте **Preview changes** для самопроверки.
5. Выберите **Propose changes**.
6. Укажите понятный заголовок, например `Улучшение перевода настроек на русский язык`.
7. Создайте Pull Request.

В описании Pull Request укажите язык, перечень улучшений и уровень владения языком.

## Что нельзя изменять

- Английский текст слева
- Спецификаторы формата: `%@`, `%ld`, `%s`, `%.1f`
- Переносы строк `\n`
- Имена файлов и метаданные заголовка
- Несколько языков в одном Pull Request

## Новые языки

Создайте issue для добавления нового языка. Мейнтейнер настроит файл.

## Процесс рецензирования

Совместная конструктивная работа. Запрещены спам, реклама и нежелательный контент.
