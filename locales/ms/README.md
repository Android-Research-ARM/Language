# Bantu Terjemahkan ARAS

ARAS diterjemahkan oleh komuniti kami. Jika anda bertutur dalam bahasa lain, anda boleh membantu menjadikan menu, butang dan mesej lebih mudah difahami oleh lebih ramai orang.

Anda tidak memerlukan pengalaman pengaturcaraan. Segalanya boleh dilakukan terus di GitHub melalui pelayar web anda.

## Cara Membantu

- Menambah bahasa yang belum disenaraikan
- Melengkapkan teks yang masih dalam bahasa Inggeris
- Membetulkan ejaan atau tatabahasa
- Menjadikan susunan ayat lebih lancar dan semula jadi
- Memastikan ketekalan istilah
- Menyemak terjemahan daripada penyumbang lain

Sebarang penambahbaikan kecil amat dialu-alukan.

## Menyunting bahasa sedia ada

1. Cari fail bahasa anda dalam senarai `.json`. Bahasa Melayu ialah `ms.json`.
2. Buka fail dan klik ikon pensel (**Edit this file**).
3. Ubah teks terjemahan di sebelah kanan sahaja.
4. Klik **Preview changes** untuk menyemak perubahan.
5. Klik **Propose changes** dan buka pull request.

```json
"Cancel": "Batal"
```

`Cancel` di sebelah kiri ialah teks asal bahasa Inggeris. `Batal` di sebelah kanan ialah terjemahan bahasa Melayu.

## Memohon bahasa baharu

Buka issue dan nyatakan nama bahasa, wilayah serta kesediaan anda untuk membantu.

## Panduan penting terjemahan

- Kekalkan `ARAS` tanpa sebarang perubahan.
- Kekalkan nama seperti Android, macOS, Mac, ProMotion dan Adreno.
- Kekalkan singkatan teknikal: ADB, QEMU, QCOW2, DPI, FPS, GiB.
- Tulis dalam bahasa Melayu yang jelas dan semula jadi.
- Pastikan teks menu dan butang ringkas.
- Gunakan istilah yang konsisten untuk peranti, tetapan, storan, kemas kini.
- Amaran pemadaman data mestilah jelas dan tegas.
- Jangan ubah penanda seperti `%@`, `%ld`, `%s`, `%.1f` atau `\n`.
- Terjemahan mesin mesti disemak oleh manusia.
- Jangan tambah sebarang iklan atau pautan peribadi.

Penanda format digantikan secara automatik semasa aplikasi dijalankan.

Rujuk [Panduan Gaya Terjemahan](STYLE_GUIDE.md) untuk butiran lanjut.
