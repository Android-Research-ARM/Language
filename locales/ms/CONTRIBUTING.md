# Menyumbang

Terima kasih atas bantuan anda menterjemah ARAS!

## Sebelum menyunting

- Semak fail yang betul
- Baca petua terjemahan
- Semak PR yang dibuka

## Menghantar perubahan

1. Buka fail
2. Sunting sebelah kanan
3. Pratonton
4. Buka Pull Request

Nyatakan butiran penambahbaikan dalam perihalan PR.

## Perkara yang tidak boleh diubah

- Kunci bahasa Inggeris di kiri
- Penanda `%@`, `%s`, `%ld`, `%.1f`
- Pemisah baris `\n`
- Metadata

## Bahasa baharu

Sila buka issue untuk bahasa baharu.
