# 贡献指南

感谢您参与 ARAS 本地化翻译！您可以通过 GitHub 网页端轻松完成所有工作。

## 编辑前准备

- 确认打开了正确的语言 JSON 文件。
- 阅读 [翻译提示](README.md#重要翻译提示)。
- 检查是否有正在进行的同语言 Pull Request，避免重复劳动。
- 仅翻译您能流利使用的语言，或请熟练者协助校对。

## 提交更改

1. 在 GitHub 上打开目标语言文件。
2. 点击铅笔图标（**Edit this file**）。
3. 仅编辑右侧的翻译内容。
4. 点击 **Preview changes** 查看修改对比。
5. 选择 **Propose changes**。
6. 填写简短明了的标题（如 `优化简体中文设置页面翻译`）。
7. 提交 Pull Request。

在 PR 描述中注明修改的语言、改进点、是否为母语者、是否使用了机翻辅助以及需要协助的词条。

## 禁止修改的内容

- 左侧的英文原文键名
- `%@`、`%ld`、`%s`、`%.1f` 等占位符
- `\n` 换行标记
- 文件顶部元数据或文件名
- 在同一个 PR 中混入多种语言修改

## 新语言申请

如需新增语言，请先提交 Issue，由维护者统一生成标准文件规范。

## 审核流程

维护者负责技术格式校验，语言贡献者负责语意流畅与术语准确。严禁任何垃圾信息或恶意内容。
