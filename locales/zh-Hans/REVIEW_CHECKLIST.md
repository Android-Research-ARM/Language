# 审核员检查清单

供项目维护者和社区校对员参考的核对标准。

## 语言与表达核查

- [ ] 译文准确表达英文原意。
- [ ] 符合简体中文母语者的表达习惯。
- [ ] 拼写、标点、语法规范统一。
- [ ] 按钮与菜单用词精炼简明。
- [ ] 核心术语在全文件中保持一致。
- [ ] 数据删除与重置警告严肃明确。
- [ ] 保留英文的未译词条已在 PR 中说明。

## 技术与格式核查

- [ ] 左侧英文键名完好无改动。
- [ ] `%@`、`%s`、`%ld`、`%.1f`、`\n` 等占位符无遗漏且顺序正确。
- [ ] 产品与专有名词拼写准确。
- [ ] 无任何广告外链或恶意注入代码。
