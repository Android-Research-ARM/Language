# Pag-ambag

Salamat sa pagtulong sa pagsasalin ng ARAS!

## Bago mag-edit

- Tiyakin ang tamang file
- Basahin ang mga tip
- Tingnan ang mga bukas na PR

## Pagsumite ng pagbabago

1. Buksan ang file
2. I-edit ang kanang bahagi
3. Silipin ang pagbabago
4. Magbukas ng Pull Request

Ilarawan ang iyong mga pagpapabuti sa deskripsyon ng PR.

## Mga hindi dapat baguhin

- Ingles na key sa kaliwa
- Mga placeholder na `%@`, `%s`, `%ld`, `%.1f`
- Mga newline `\n`
- Metadata

## Mga bagong wika

Mangyaring magbukas muna ng issue para sa bagong wika.

## Proseso ng pagsusuri

Pagtutulungang may paggalang sa isa't isa.
