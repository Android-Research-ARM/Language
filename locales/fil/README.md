# Tumulong sa Pagsasalin ng ARAS

Ang ARAS ay isinasalin ng ating komunidad. Kung marunong ka ng ibang wika, makakatulong ka upang maging natural at madaling maunawaan ang mga menu, button, at mensahe para sa mas maraming tao.

Hindi mo kailangan ng karanasan sa programming o espesyal na software. Lahat ay maaaring gawin sa GitHub gamit ang iyong web browser.

## Mga Paraan para Tumulong

- Magdagdag ng wikang wala pa sa listahan
- Kumpletuhin ang mga tekstong nasa Ingles pa
- Magwasto ng baybay o gramatika
- Gawing mas natural ang mga pangungusap sa Filipino
- Panatilihin ang pagkakapare-pareho ng mga termino
- Suriin ang mga salin mula sa ibang contributor

Malugod naming tinatanggap ang bawat munting tulong.

## Pag-edit ng umiiral na wika

1. Hanapin ang iyong wika sa listahan ng mga `.json` file. Ang Filipino ay `fil.json`.
2. Buksan ang file at i-click ang lapis (**Edit this file**).
3. Baguhin lamang ang isinaling teksto sa kanang bahagi.
4. I-click ang **Preview changes** upang suriin ang pagbabago.
5. I-click ang **Propose changes** at magbukas ng pull request.

```json
"Cancel": "Kanselahin"
```

Ang `Cancel` sa kaliwa ay ang orihinal na Ingles. Ang `Kanselahin` sa kanan ay ang salin sa Filipino.

## Paghiling ng bagong wika

Magbukas ng issue at sabihin ang pangalan ng wika, rehiyon, at kung maaari kang magsalin o magsuri.

## Mahahalagang paalala sa pagsasalin

- Panatilihin ang `ARAS` nang walang pagbabago.
- Panatilihin ang mga pangalan tulad ng Android, macOS, Mac, ProMotion, at Adreno.
- Panatilihin ang mga teknikal na daglat: ADB, QEMU, QCOW2, DPI, FPS, GiB.
- Magsulat sa natural na wikang Filipino.
- Gawing maikli ang mga teksto ng menu at button.
- Maging pare-pareho sa mga salita para sa device, settings, storage, update.
- Dapat malinaw at seryoso ang mga babala sa pagbura ng data.
- Huwag baguhin ang mga placeholder tulad ng `%@`, `%ld`, `%s`, `%.1f`, o `\n`.
- Dapat suriin ng tao ang mga machine translation.
- Huwag maglagay ng anunsyo o personal na impormasyon.

Awtomatikong pinapalitan ng programa ang mga placeholder habang tumatakbo.

Tingnan ang [Translation Style Guide](STYLE_GUIDE.md) para sa higit pang detalye.
