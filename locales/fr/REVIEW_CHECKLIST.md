# Liste de contrôle pour les relecteurs

Cette liste s'adresse aux mainteneurs et relecteurs communautaires.

## Relecture linguistique

- [ ] La traduction respecte fidèlement le sens original anglais.
- [ ] Le texte est fluide et naturel en français.
- [ ] La grammaire, l'orthographe et la ponctuation sont impeccables.
- [ ] Les libellés de boutons et de menus sont concis.
- [ ] Les termes techniques récurrents sont harmonisés.
- [ ] Les avertissements de suppression de données restent explicites.
- [ ] Les termes laissés en anglais sont signalés dans la pull request.

## Relecture technique

- [ ] Les clés anglaises de gauche sont inchangées.
- [ ] Les balises `%@`, `%s`, `%ld`, `%.1f` et `\n` sont préservées.
- [ ] Les noms de marques et abréviations sont préservés.
- [ ] Aucun lien externe non sollicité n'a été inséré.
- [ ] Les propositions issues d'IA ont été relues avec soin.
