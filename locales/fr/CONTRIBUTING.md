# Contribuer

Merci de participer à la traduction d'ARAS ! Tout peut être réalisé via GitHub sans outils techniques particuliers.

## Avant de modifier

- Vérifiez que vous avez ouvert le bon fichier de langue.
- Lisez les [conseils de traduction](README.md#conseils-importants-pour-la-traduction).
- Vérifiez les pull requests ouvertes pour éviter les doublons.
- Traduisez vers une langue que vous maîtrisez parfaitement ou demandez une relecture.

## Soumettre une modification

1. Ouvrez le fichier de langue sur GitHub.
2. Cliquez sur l'icône de crayon (**Edit this file**).
3. Modifiez uniquement le texte traduit sur le côté droit.
4. Utilisez **Preview changes** pour vérifier vos ajouts.
5. Sélectionnez **Propose changes**.
6. Indiquez un titre clair, par exemple : `Amélioration des traductions des réglages en français`.
7. Ouvrez la pull request.

Dans votre pull request, veuillez préciser :

- La langue modifiée
- Les améliorations apportées
- Si vous êtes locuteur natif ou fluide
- Si vous avez utilisé un outil de traduction automatique
- Les phrases nécessitant éventuellement une relecture supplémentaire

## Ce qu'il ne faut pas modifier

- Le texte original en anglais sur la gauche
- Les balises commençant par `%` comme `%@`, `%ld`, `%s` ou `%.1f`
- Les marqueurs de saut de ligne `\n`
- Les noms de fichiers ou les métadonnées en tête de fichier
- Plusieurs langues dans une même pull request

## Nouvelles langues

Ouvrez une issue avant de créer un fichier. Indiquez la langue, la variante régionale, son nom natif et votre disponibilité.

## Processus de relecture

Les mainteneurs vérifient la conformité technique du fichier. Les relecteurs vérifient la fluidité, l'orthographe et la cohérence.

Tout contenu promotionnel, lien indésirable, message hostile ou donnée personnelle est strictement interdit.

Ne soumettez que des traductions dont vous détenez les droits. En ouvrant une pull request, vous acceptez la publication sous [Licence MIT](../../LICENSE).
