# योगदान गाइड

ARAS के अनुवाद में मदद करने के लिए धन्यवाद! सब कुछ सीधे GitHub के माध्यम से किया जा सकता है।

## संपादन से पहले

- सही फ़ाइल की पुष्टि करें
- अनुवाद सुझाव पढ़ें
- खुली हुई PR जांचें

## परिवर्तन सबमिट करना

1. फ़ाइल खोलें
2. दाईं ओर संपादन करें
3. पूर्वावलोकन करें
4. Pull Request खोलें

Pull Request विवरण में किए गए सुधारों की जानकारी दें।

## क्या न बदलें

- बाईं ओर की अंग्रेजी कुंजियाँ
- `%@`, `%s`, `%ld`, `%.1f` प्लेसहोल्डर
- `\n` न्यूलाइन
- मेटाडेटा

## नई भाषाएं

कृपया नई भाषा के लिए पहले एक Issue खोलें।

## समीक्षा प्रक्रिया

गुणवत्ता और परस्पर सहयोग आधारित प्रक्रिया। स्पैम वर्जित है।

## साझा करने की अनुमति

सभी योगदान [MIT लाइसेंस](../../LICENSE) के तहत प्रकाशित होते हैं।
