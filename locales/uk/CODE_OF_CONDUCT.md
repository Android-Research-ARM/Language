# Кодекс поведінки спільноти

Спільнота ARAS рада кожному учаснику.

## Очікувана поведінка

- Ввічливість, терпіння, взаємоповага
- Конструктивне обговорення
- Захист приватності

## Неприйнятна поведінка

- Образи, дискримінація, погрози
- Спам та навмисно хибні переклади

## Забезпечення правил

Мейнтейнери вживатимуть заходів для безпеки спільноти.
