# Чек-лист для перевірки

Посібник для мейнтейнерів та рецензентів спільноти.

## Мовна перевірка

- [ ] Точний зміст
- [ ] Грамотна українська мова
- [ ] Єдина термінологія
- [ ] Чіткі застереження

## Технічна перевірка

- [ ] Ключі ліворуч без змін
- [ ] Маркери `%@`, `%s`, `%ld`, `%.1f`, `\n` цілі
- [ ] Без спаму
