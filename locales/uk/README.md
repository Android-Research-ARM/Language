# Допоможіть перекласти ARAS

ARAS перекладається силами нашої спільноти. Якщо ви володієте іншими мовами, ви можете допомогти зробити меню, кнопки та повідомлення природними для більшої кількості користувачів.

Вам не потрібен досвід програмування чи спеціальне програмне забезпечення. Усе можна робити безпосередньо на GitHub у веббраузері.

## Як ви можете допомогти

- Додати мову, якої ще немає в переліку
- Завершити переклад текстів, що залишилися англійською
- Виправити орфографію або граматику
- Зробити формулювання природнішими
- Покращити узгодженість термінів
- Перевірити переклад іншого автора

Будь-які невеликі покращення вітаються. Не обов'язково перекладати весь файл одразу.

## Редагування наявної мови

1. Знайдіть мову у списку файлів `.json`. Наприклад, українська — це `uk.json`.
2. Відкрийте файл і натисніть кнопку з олівцем (**Edit this file**).
3. Змінюйте лише перекладений текст праворуч.
4. Натисніть **Preview changes** для перевірки.
5. Натисніть **Propose changes** і відкрийте pull request.

```json
"Cancel": "Скасувати"
```

`Cancel` ліворуч — це оригінал англійською. `Скасувати` праворуч — український переклад.

## Запит на нову мову

Створіть issue та вкажіть назву мови, регіон та чи можете ви перекладати або перевіряти.

## Важливі поради щодо перекладу

- Залишайте `ARAS` без змін. Це назва продукту.
- Зазвичай залишайте без змін назви Android, macOS, Mac, ProMotion та Adreno.
- Зберігайте технічні абревіатури: ADB, QEMU, QCOW2, DPI, FPS, GiB.
- Пишіть природною українською мовою.
- Робіть тексти кнопок і меню короткими.
- Вживайте однакові терміни для «пристрій», «параметри», «сховище», «оновлення».
- Попередження про видалення даних мають бути чіткими та однозначними.
- Не змінюйте спеціальні маркери: `%@`, `%ld`, `%s`, `%.1f` або `\n`.
- Машинний переклад обов'язково має перевірити людина.
- Ніколи не додавайте рекламу чи приватну інформацію.

Спеціальні маркери на зразок `%@`, `%ld`, `%s`, `%.1f` та `\n` замінюються автоматично під час роботи програми.

Дивіться [посібник зі стилю перекладу](STYLE_GUIDE.md) для деталей.

## Назви мовних файлів
