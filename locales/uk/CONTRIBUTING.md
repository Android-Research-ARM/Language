# Участь у перекладі

Дякуємо за допомогу в перекладі ARAS! Усе можна зробити через GitHub.

## Перед редагуванням

- Перевірте мовний файл
- Прочитайте поради
- Перевірте відкриті PR

## Подання змін

1. Відкрийте файл
2. Відредагуйте текст праворуч
3. Перегляньте зміни
4. Створіть запит на злиття

Опишіть зроблені зміни та рівень володіння мовою в описі pull request.

## Що не слід змінювати

- Англійські ключі ліворуч
- Маркери `%@`, `%s`, `%ld`, `%.1f`
- Розриви рядків `\n`
- Метадані

## Нові мови

Створіть issue для додавання нової мови.

## Процес перевірки

Спільна робота над якістю. Спам та образи заборонені.
