# Bijdragen

Bedankt voor je hulp bij het vertalen van ARAS! Alles verloopt eenvoudig via GitHub.

## Vóór het bewerken

- Controleer of je het juiste bestand hebt geopend.
- Lees de [vertaaltips](README.md#belangrijke-vertaaltips).
- Bekijk openstaande pull requests om dubbel werk te voorkomen.
- Vertaal naar talen die je vloeiend beheerst.

## Wijzigingen indienen

1. Open het bestand op GitHub.
2. Klik op het potloodpictogram (**Edit this file**).
3. Bewerk alleen de rechterkant.
4. Controleer met **Preview changes**.
5. Kies **Propose changes**.
6. Geef een duidelijke titel aan je voorstel.
7. Open de pull request.

Vermeld in je pull request de taal, verbeteringen, taalkennis en eventuele vragen.

## Wat niet te wijzigen

- Engelse tekst aan de linkerkant
- Markeringen zoals `%@`, `%ld`, `%s`, `%.1f`
- Regelovergangen `\n`
- Metagegevens en bestandsnamen
- Meerdere talen in één pull request

## Nieuwe talen

Open een issue voor nieuwe talen. Een beheerder maakt het bestand aan.

## Beoordelingsproces

Samenwerking en kwaliteit staan voorop. Geen spam of persoonlijke data toegestaan.
