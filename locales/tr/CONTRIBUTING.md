# Katkıda Bulunma

ARAS'ı çevirmeye yardımcı olduğunuz için teşekkür ederiz! Tüm süreci GitHub üzerinden yönetebilirsiniz.

## Düzenlemeden önce

- Doğru dosyayı açtığınızı kontrol edin
- İpuçlarını okuyun
- Açık pull request'leri inceleyin

## Değişiklik gönderme

1. Dosyayı açın
2. Sağ tarafı düzenleyin
3. Değişiklikleri önizleyin
4. Pull request oluşturun

Pull request açıklamasında yaptığınız iyileştirmeleri ve dil bilginizi belirtin.

## Değiştirilmemesi gerekenler

- Soldaki İngilizce anahtarlar
- `%@`, `%s`, `%ld`, `%.1f` belirteçleri
- `\n` satır sonları
- Üstveri bilgileri

## Yeni diller

Yeni bir dil için lütfen önce bir issue açın.

## İnceleme süreci

İş birliği ve kalite odaklı süreç. Spam ve kötü niyetli içerikler yasaktır.
