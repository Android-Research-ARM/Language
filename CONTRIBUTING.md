# Contributing

Thank you for helping translate ARAS. You can contribute entirely through the GitHub
website; no programming tools are required.

## Before editing

- Check that you opened the correct language file.
- Read the [translation tips](README.md#important-translation-tips).
- Search open pull requests to see whether someone is already changing the same language.
- Translate languages you speak fluently, or ask a fluent speaker to review your work.

## Submit a change

1. Open the language file on GitHub.
2. Click the pencil-shaped **Edit this file** button.
3. Edit translated text on the right side only.
4. Use **Preview changes** to check what you changed.
5. Select **Propose changes**.
6. Give your proposal a short title, such as `Improve French settings translation`.
7. Open the pull request.

In your pull request, tell us:

- Which language you changed
- What you improved
- Whether you are a fluent or native speaker
- Whether you used machine translation
- Which phrases, if any, still need help

## What not to change

Do not change:

- English text on the left side
- Text beginning with `%`, such as `%@`, `%ld`, `%s`, or `%.1f`
- `\n` markers
- Language filenames or the information at the top of a file
- More than one language in the same pull request

If any of those need changing, open an issue and a maintainer will help.

## New languages

Please open an issue instead of creating the file yourself. Tell us the language, region if
applicable, its name written in that language, and whether you can translate or review it.
A maintainer will prepare the file so you can focus on the words.

## Review process

Maintainers check that ARAS can safely read the file. Fluent speakers review meaning,
grammar, tone, and consistency. We may ask questions or suggest changes before accepting a
translation. This is collaborative editing, not a test, and corrections remain welcome
after a translation is published.

Do not include hidden messages, harassment, promotion, links, tracking, personal details,
or text unrelated to the English phrase.

## Permission to share

Only submit translations you have the right to share. By opening a pull request, you agree
to make your contribution available under the repository's [MIT License](LICENSE).
